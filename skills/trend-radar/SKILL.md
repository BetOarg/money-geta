# Trend radar

1. Query recent public videos using the configured research tool or the upstream trend script if installed.
2. Record title, creator, URL, published time, views, retrieval time and the source used for each metric.
3. Calculate views per hour only when both views and age are available; label it an estimate and state the calculation.
4. Prioritize official sources and creators whose reuse terms are known.
5. Exclude leaks, piracy, early-access circumvention and unverified claims.
6. Present no more than ten candidates, then recommend up to three with a clear reason.
7. If metrics cannot be retrieved, say so. Never invent a trend ranking.

Suggested next workflow: moment-finder on a selected source. Trend rank is not a measure of reuse permission.
