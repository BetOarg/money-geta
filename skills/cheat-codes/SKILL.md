# Cheat codes

Use only the repository reference file and independently check each entry's source and status.

## Publication gate

- **UNVERIFIED / REPORTED**: research lead only. Do not publish as a confirmed code or include in a "working cheats" carousel.
- **VERIFIED**: may be drafted only when the code appears in a cited guide and has been tested in-game, with tester and date recorded.
- **WRONG / FAKE**: never publish as working; publish a correction if previously shared.

Before launch or before in-game testing is possible, clearly label content as unverified research and do not present it as an actionable code list.

Never invent button sequences, effects, platforms or unlock requirements. Do not copy entries from fake-code lists. Do not promote mod menus, online exploits, money glitches or cheating that harms other players.

## Carousel workflow

1. Filter to verified entries only.
2. Confirm platform, exact input sequence, effect and any unlock conditions.
3. Include the source and verification date in working notes.
4. Have a human review every slide and caption.
5. Do not publish without explicit approval.
