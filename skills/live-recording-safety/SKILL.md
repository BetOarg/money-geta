# Live recording safety

1. Confirm the source is public and the operator has permission to record and reuse it. A publicly viewable stream is not automatically licensed for reposting.
2. Use a unique directory for every recording session. Never delete, truncate, reuse or overwrite previous recordings, chat logs, indexes or clips.
3. If a destination already contains files, create a new session directory; do not clean it automatically.
4. Check available disk space and the configured retention policy before starting.
5. Keep API keys, cookies, OAuth tokens and private chat data out of logs, commits and shared artifacts.
6. Stop capture cleanly and report any incomplete segment files.
7. Require a human to inspect each proposed clip, verify creator attribution and confirm publishing rights.
8. Do not auto-upload or publish. Obtain explicit approval for each final post.

A technical recording success is not proof of permission to publish.
